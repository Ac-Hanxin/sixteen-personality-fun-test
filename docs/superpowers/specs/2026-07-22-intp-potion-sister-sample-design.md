# INTP「药水姐」样本设计

## 目标

先生成一张 1:1 的 INTP 单角色样本，用它确认整套 16 型角色的统一画风。当前阶段不生成其余角色，也不制作一体版。

## 画面规格

- 画风：现代编辑插画风的扁平矢量效果，简单几何形，纯色块，仅保留约 10% 的轻微明暗层次。
- 构图：单人、居中、上半身为主，盘腿坐姿，人物与关键道具完整可见，适合后续 README 方形网格。
- 背景：纯净的极浅灰白色 `#f7f8fb`，不出现复杂场景。
- 人物：年轻女性，松散低马尾，圆眼镜，宽松藏蓝色开衫；神态放松、好奇，侧目观察手中的烧瓶。
- 标志物：一只装有轻微冒泡青绿色液体的小玻璃烧瓶。
- 辅助物：人物旁边放置老式黄铜钟表结构、少量散落齿轮，以及一本摊开的图解笔记本。
- 配色：藏蓝作为主点缀，青绿色仅用于药水；整体克制、干净。
- 禁止项：文字、Logo、水印、3D 渲染、厚涂油画、写实摄影、长袍、斗篷、贝雷帽，以及与现有品牌吉祥物一眼相似的具体设计。

## 生图提示词

```text
Use case: stylized-concept
Asset type: square character illustration and visual style anchor for a 16-character gallery
Scene/backdrop: plain very-light background #f7f8fb
Subject: A relaxed young woman with a loose low ponytail and round glasses, wearing an oversized navy cardigan, sitting cross-legged and holding up a small glass flask of gently bubbling teal liquid with a curious sideways glance. An old brass clockwork and a few scattered gears sit on the floor beside her, together with an open notebook of diagrams.
Style/medium: flat vector illustration, clean modern editorial style, simple geometric shapes, solid colors with subtle 10% tint shading
Composition/framing: 1:1 square, one original character, centered upper-body portrait, key props fully visible, balanced spacing
Color palette: deep navy accent palette, teal liquid, restrained neutral background
Constraints: original character design; clean silhouette; no text, no logo, no watermark
Avoid: 3D render, painterly, photorealistic, long robe, cloak, beret, copying or closely resembling any existing brand mascot
```

## 验收标准

1. 一眼能识别“圆眼镜年轻女性 + 青绿色烧瓶”的药水姐标志。
2. 扁平矢量感明确，不出现 3D、厚涂或写实质感。
3. 人物、姿势、发型与服装具有原创性，不与 16Personalities 的具体角色设计撞形。
4. 方形缩略图尺寸下，人物和烧瓶仍是清晰视觉中心。
5. 背景、文字和品牌元素符合约束。
